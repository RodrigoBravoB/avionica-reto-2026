# Avionica Reto 2026

## Descripción

Proyecto desarrollado para el reto de reclutamiento de la División de Aviónica AAIAQ, Otoño 2026.

El proyecto consiste en desarrollar un sistema de adquisición y procesamiento de datos de telemetría a partir de una simulación educativa. El sistema permitirá generar registros, validar mediciones, procesar datos y obtener información relevante mediante análisis y visualización.

## Objetivo

Desarrollar un programa capaz de procesar registros de telemetría simulada, detectar y descartar datos corruptos, aplicar técnicas de filtrado, calcular magnitudes derivadas y generar resultados gráficos.
